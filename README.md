# ecg-som

Disentangled representation learning for ECG signals using a DPSOM (Deep Probabilistic Self-Organizing Map) architecture on the PTB-XL dataset.

The model learns a morphology latent space (z) that drives SOM assignments, using three independent lead-wise convolutional encoders — one for morphology (z), one for age (z_age), one for sex (z_sex). Disentanglement happens via SOM residualization: linear probes fit directly on z find the age and sex directions within the morphology space, and those directions are projected out of z before it is used for SOM clustering — the z_age/z_sex branches themselves only drive the separate age/sex prediction heads. A disease-conditioned age-correction module further refines age predictions using top-k SOM node embeddings.

## Quick start

```bash
# from repo root
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install -r explorer/requirements.txt   # optional, for the web explorer

# train with default config (uses data/ptbxl_100_T-12ms.pkl if present,
# otherwise imports from data/PTB-XL/)
python -m src.training.trainer

# or customize SOM size, epochs, seed, etc.
python -m src.training.trainer --som-dim 16 16 --epochs 40 --seed 42
```

## Explorer

An interactive SOM explorer is available as a FastAPI + D3 web app (auto-loads the best checkpoint on startup, scopes datasets to `data/`, and supports fast compact `.npz` loading + lazy cell inspection):

```bash
# optional one-time export from 3.6 GB pickle -> compact per-split .npz (~60 MB for test)
python explorer/export_compact_data.py

# run locally
python explorer/server.py [--port 8050] [--host 0.0.0.0]

# or via Docker Compose
docker compose -f explorer/docker-compose.yml up --build -d
```

Open `http://localhost:8050` in a browser to browse SOM nodes, inspect 12-lead ECG prototypes and percentile bands, and predict Age / Sex / SOM placement on new ECG files directly from the sidebar.

![ECG-SOM Explorer](explorer/explorer.png)

## Predicting on new ECG data

Use [`src/inference.py`](src/inference.py) to convert and predict on any new 12-lead ECG (WFDB `.hea`/`.dat`, `.npy`, `.npz`, or `.csv` at any sampling rate — automatically resampled to 100 Hz):

```bash
# predict age, sex & SOM cluster using the best model automatically (or pass --ckpt)
python -m src.inference --input path/to/ecg.npy --fs 500

# or convert a directory of ECGs into an Explorer-compatible dataset pickle
python -m src.inference --convert-dir path/to/ecgs/ --output data/custom_ecgs.pkl --fs 500
```

## Ablation studies

```bash
# run all ablation variants in parallel across 2 GPUs
bash ablation/run_ablation_parallel.sh

# or run specific variants
python ablation/ablation.py --variants baseline no_temporal no_disentangle
```

Results are written to `ablation/ablation_results*.csv/json` and merged into `ablation_results_all.csv`.
The notebook `ablation/ablation_exploration.ipynb` visualises all results interactively.

### Results summary

All 48 ablation variants completed successfully on PTB-XL test split.

| Metric | Meaning | Direction |
|--------|---------|-----------|
| NMI | Normalised Mutual Information (cluster ↔ disease label) | ↑ better |
| AMI | Adjusted Mutual Information | ↑ better |
| Purity | Majority-class fraction per SOM node | ↑ better |
| MAE Age | Mean absolute error for age regression (years) | ↓ better |
| AUC Sex | AUROC for sex classification | ↑ better |

**Baseline (8×8 SOM):** NMI = 0.208 · AMI = 0.200 · Purity = 0.538 · MAE Age = 7.78 · AUC Sex = 0.901

### Loss-term ablations

Removing individual loss components from the full model.

| Variant | Removed / changed | NMI | AMI | Purity | MAE Age | AUC Sex |
|---|---|---|---|---|---|---|
| **baseline** | — | **0.208** | **0.200** | **0.538** | 7.78 | **0.901** |
| no_kl | γ = 0 (no SOM commitment KL(p ‖ q)) | 0.000 | 0.000 | 0.449 | 7.71 | 0.896 |
| no_som_smooth | α = 0 (Student-t df clamped to 1e-4) | 0.141 | 0.133 | 0.492 | 7.69 | 0.894 |
| no_temporal | τ = 0 (no temporal beat-sequence loss) | 0.178 | 0.169 | 0.526 | 7.73 | 0.898 |
| no_som_commit | β = 0 (no SOM neighbourhood smoothing) | 0.205 | 0.197 | 0.529 | 7.65 | 0.899 |
| no_record_attn | η = 0 (no record-level attention pooling) | 0.206 | 0.198 | 0.544 | 7.56 | 0.898 |
| no_disentangle | δ_age = δ_sex = 0 (demographic supervision off; probes still run) | 0.198 | 0.189 | 0.534 | 19.60 | 0.385 |
| no_age | δ_age = 0 (age supervision off) | 0.202 | 0.194 | 0.535 | 19.14 | 0.901 |
| no_sex | δ_sex = 0 (sex supervision off) | 0.213 | 0.205 | 0.546 | 7.66 | 0.648 |
| no_age_corr | λ_max = 0 (age-correction module off) | 0.200 | 0.192 | 0.538 | 7.51 | 0.902 |

Key findings:
- **SOM commitment loss (`γ · KL(p ‖ q)`) is essential** — removing it (`no_kl`, `γ = 0`) collapses NMI to 0.
- **Demographic supervision drives the age/sex branches** — setting `δ_age = δ_sex = 0` (`no_disentangle`) leaves the demographic heads untrained (raising MAE Age from 7.8 to 19.6 years and dropping sex AUC to 0.385), while SOM residualization probes continue to run independently.
- **Temporal smoothing matters most among auxiliary losses** — `no_temporal` (`τ = 0`) drops NMI by −0.030.
- **Student-t degrees of freedom (`α`) strongly affect clustering** — clamping `α → 1e-4` (`no_som_smooth`) drops NMI by −0.067.

## Requirements

- Python 3.10+
- CUDA-capable GPU recommended for training speed

## Dataset

This project uses [PTB-XL](https://physionet.org/content/ptb-xl/), a large publicly available ECG dataset, together with per-record quality labels (`data/ptbxl_error_labels.csv`) from [ecg-data-repo](https://github.com/explainable-ecg-learning/ecg-data-repo).
Download and unpack PTB-XL to `data/PTB-XL/` before running (if `data/ptbxl_100_T-12ms.pkl` is not already present). During training, `train`/`val` apply both `ecg-som`'s noise/beat-segmentation filters and `ecg-data-repo`'s quality curation (`max_error_severity = 2`, excluding `3_severe_error` and `err_scp_zero_diagnostic`).
